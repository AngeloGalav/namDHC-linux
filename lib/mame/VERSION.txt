Local changes:

  src/osd/modules/lib/osdlib_unix.cpp
    When NAMDHC_NO_SDL is defined the SDL header is not included and the
    clipboard functions use the stub implementation (chdman never uses the
    clipboard). Search for NAMDHC_NO_SDL.

To update: replace these folders with the same paths from a newer MAME
checkout, reapply the change above, update chdman/version.cpp and rebuild.
If new source files are needed the linker will report the missing symbols;
add the corresponding .cpp to lib/mame/CMakeLists.txt.
